# SKU Generator Guide for Bedding Lounge

## SKU Format Structure
`[CATEGORY]-[MATERIAL]-[SIZE]-[COLOR]`

## Category Codes
- **BED** = Bedsheets
- **DUV** = Duvet Covers  
- **PIL** = Pillows
- **BLK** = Blankets
- **THR** = Throws

## Material Codes
### Bedsheets & Duvet Covers
- **COT** = Cotton
- **EGY** = Egyptian Cotton
- **BAM** = Bamboo
- **LIN** = Linen
- **SIL** = Silk
- **MIC** = Microfiber
- **PER** = Percale
- **JER** = Jersey

### Pillows
- **MEM** = Memory Foam
- **DOW** = Down
- **SYN** = Synthetic
- **LAT** = Latex
- **GEL** = Gel
- **FIB** = Fiber Fill

## Size Codes
### Bedsheets & Duvet Covers
- **T** = Twin (36" x 75")
- **TXL** = Twin XL (36" x 80")
- **F** = Full (54" x 75")
- **Q** = Queen (60" x 80")
- **K** = King (76" x 80")
- **CK** = California King (72" x 84")

### Pillows
- **STD** = Standard (20" x 26")
- **Q** = Queen (20" x 30")
- **K** = King (20" x 36")
- **EUR** = European (26" x 26")
- **BOD** = Body (20" x 54")

## Color Codes
- **WHT** = White
- **BLK** = Black
- **GRY** = Grey
- **BLU** = Blue
- **GRN** = Green
- **BRN** = Brown
- **BEI** = Beige
- **CRM** = Cream
- **NAV** = Navy
- **RED** = Red
- **PNK** = Pink
- **PUR** = Purple
- **YEL** = Yellow
- **ORG** = Orange

## Example SKUs
- `BED-EGY-Q-WHT` = Egyptian Cotton Queen Bedsheet in White
- `DUV-LIN-K-NAV` = Linen King Duvet Cover in Navy
- `PIL-MEM-STD-WHT` = Memory Foam Standard Pillow in White
- `BED-BAM-F-GRY` = Bamboo Full Bedsheet in Grey

## SKU Validation Rules
1. Must be unique across all products
2. Maximum 20 characters
3. Use only uppercase letters and hyphens
4. Follow the exact format structure
5. No spaces or special characters except hyphens

## Quick SKU Generator Tool
Use this format to create new SKUs:
1. Choose category code
2. Choose material code  
3. Choose size code
4. Choose color code
5. Combine with hyphens: `CATEGORY-MATERIAL-SIZE-COLOR`

## Common Mistakes to Avoid
- ❌ Using lowercase letters
- ❌ Adding extra characters or spaces
- ❌ Creating duplicate SKUs
- ❌ Using undefined codes
- ❌ Mixing up size codes between categories
